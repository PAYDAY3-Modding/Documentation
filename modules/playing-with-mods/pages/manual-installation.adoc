= Manual Installation
:description: Download PAYDAY 3 mods from ModWorkshop and install complete PDML mod folders into PAYDAY3/Mods/.

The recommended workflow is to install PDML mods as complete folders under `PAYDAY3/Mods/`. Close PAYDAY 3 before adding, updating, or removing mod files.

== Download a mod

. Open https://modworkshop.net/g/payday-3[PAYDAY 3 on ModWorkshop] and choose a mod.
. Read its description, dependencies, and installation instructions. Check that the release supports your game version, and choose the PDML version when one is available.
. Download the mod and any required dependencies. Extract downloaded archives so you can copy the complete mod folders into the game.

== Find the game folder

Open PAYDAY 3's installation folder using your game launcher. In Steam, right-click *PAYDAY 3* in your library and select *Manage > Browse local files*.

For Epic Games, open the game's three-dot menu in your library, select *Manage*, then click the folder icon beside the installation location. In the Xbox app, right-click the game, select *Manage > Files*, then *Browse*.

In these guides, `PAYDAY3/Mods/` means the `Mods` folder beside the game's runtime `Content` folder. It is inside the installation folder opened by your launcher. Use the location for your storefront below, where `<InstallFolder>` means the folder opened by the launcher:

[cols="1,3"]
|===
|Storefront |Mod folder

|Steam or Epic Games
|`<InstallFolder>/PAYDAY3/Mods/`

|Xbox / Microsoft Store
|`<InstallFolder>/Content/PAYDAY3/Mods/`
|===

For example, a Steam installation has two `PAYDAY3` folders. Put `Mods` in the inner one:

[source,text]
----
steamapps/common/PAYDAY3/
`-- PAYDAY3/
    |-- Content/
    `-- Mods/
----

== Install PDML

PDML loads compatible mods when the game starts. Install it once before adding other PDML mods.

. Close PAYDAY 3.
. Open https://modworkshop.net/mod/59255[PAYDAY 3 MOD LOADER by Nadz] and download the release compatible with your game. Check its *Dependencies & Instructions* tab for any release-specific changes.
. Extract the ZIP into a temporary folder and locate `PDML.uplugin`, `Content`, and `Resources`.
. Open the `Mods` folder shown for your storefront above. If it does not exist, create it in that location. Inside `Mods`, create a folder named `PDML`.
. Copy `PDML.uplugin`, `Content`, and `Resources` together into `Mods/PDML/`. If extraction already created a `PDML` folder containing these items, copy that whole folder into `Mods` instead.

Check the result before launching:

[source,text]
----
PAYDAY3/
`-- Mods/
    `-- PDML/
        |-- PDML.uplugin
        |-- Resources/
        `-- Content/
            `-- Paks/
                |-- Windows/
                `-- WinGDK/
----

Keep both supplied platform folders and all packaged files together. `PDML.uplugin` must be directly inside `Mods/PDML/`, without another `PDML` or download folder in between.

*Check:* Start PAYDAY 3 and look for the Mod Manager in the main menu. If it is missing, close the game, check the storefront path and `PDML.uplugin` location above, and try again. If it is still missing, check the release's compatibility notes before adding other mods.

These steps follow the https://modworkshop.net/mod/59255[PDML author's installation instructions].

== Install a PDML mod

Put the *whole mod folder* in:

[source,text]
----
PAYDAY3/Mods/
----

. Open the game's `PAYDAY3` directory and create a folder named `Mods` if it does not exist.
. Find the extracted mod folder containing its `.uplugin` file.
. Copy that complete folder into `Mods`, preserving every file and subfolder supplied by the author.
. Install required PDML dependencies in the same way, following any additional instructions on their download pages.
. Start PAYDAY 3 with PDML installed and check that the mod is loaded.

*Check:* Open the in-game Mod Manager and find the mod by its displayed name, which may differ from its folder name. Then check the change described on the mod's download page.

Your other mod folders go beside `PDML`, not inside it. For example:

[source,text]
----
PAYDAY3/
`-- Mods/
    |-- ExampleMod/
    |   |-- ExampleMod.uplugin
    |   `-- ... all supplied files and subfolders ...
    `-- AnotherMod/
        |-- AnotherMod.uplugin
        `-- ... all supplied files and subfolders ...
----

[IMPORTANT]
====
Keep each PDML mod together as one folder. Its `.uplugin` file should be directly inside that folder, for example `PAYDAY3/Mods/ExampleMod/ExampleMod.uplugin`.

Avoid adding an extra archive wrapper folder such as `PAYDAY3/Mods/ExampleMod-download/ExampleMod/`. Keep the packaged content inside the mod folder; do not extract individual `.pak`, `.utoc`, or `.ucas` files into `Content/Paks/~mods`.
====

See xref:pdml:loading.adoc[PDML Mod Loading] for more on how PDML discovers these folders.

== Update or remove a mod

Close the game and follow the author's update instructions. Replace the old mod folder with the complete new version, keeping any mod-specific configuration the author tells you to preserve. To uninstall a PDML mod, remove its folder from `PAYDAY3/Mods/`.

If the mod is missing from the Mod Manager, close the game, check that its `.uplugin` file is directly inside its mod folder and all dependencies are installed, then restart. If it is listed but causes a crash or has no effect, check its compatibility and try it without other mods. Use the mod's ModWorkshop page to check for updates or report the problem to its author.

== Older loose PAK mods

Loose PAK installations are being phased out in favour of PDML. Use this method only for a download distributed as a loose PAK mod; moving a PAK file into `PAYDAY3/Mods/` does not turn it into a PDML mod.

Follow the author's instructions, usually copying the `.pak` file and any matching `.utoc` and `.ucas` files into `PAYDAY3/Content/Paks/~mods/`. Keep matching files together. PAYDAY 3 on UE5 loads these directly without a PAK unlocker or extra launch option.

To remove a loose PAK mod, close the game and remove its files from `~mods`. When switching to a PDML release of the same mod, remove the old loose PAK version first.
