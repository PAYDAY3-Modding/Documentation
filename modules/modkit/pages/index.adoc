= The Modkit

The PAYDAY 3 modkit is the development project used to author CrimeFactory and PDML mods against the current PAYDAY 3 game.

It combines:

* the custom Unreal Engine {pd3-engine-version} editor,
* the PAYDAY 3 modkit project,
* the game's `AssetRegistry.bin`,
* a JMAP generated from the running game,
* Suzie-generated native PAYDAY 3 runtime classes,
* CrimeFactory,
* PDML,
* the modified Wwise integration and matching Audiokinetic `ThirdParty` SDK files,
* and direct access to supported cooked PAYDAY 3 content from the user's installed game.

The modkit does not redistribute PAYDAY 3's cooked game content. Instead, the custom editor mounts the user's local game installation and exposes supported assets in the editor.

== What the modkit gives you

With the required setup complete, the editor can:

* expose supported PAYDAY 3 cooked assets under their original `/Game/...` paths,
* open many cooked assets in read-only form so their defaults can be inspected,
* load supported cooked audio assets through the configured Wwise integration,
* resolve references to native PAYDAY 3 classes generated by Suzie,
* create new mod plugins through CrimeFactory,
* convert some supported cooked assets into editable uncooked replacements,
* create partial uncooked/stubbed starting points for more complex assets,
* and Forge plugin mods for PDML.

== Required runtime data

The cooked-content workflow depends on the following local data and configuration:

[cols="1,3"]
|===
|Requirement |Purpose

|PAYDAY 3 game path
|Tells the custom editor where the installed game content is located.

|PAYDAY 3 AES key
|Allows the editor to access the encrypted game containers.

|`AssetRegistry.bin`
|Placed in the modkit root. It tells the editor which cooked PAYDAY 3 assets exist and allows those assets to be exposed in the Content Browser.

|JMAP in `Content/DynamicClasses`
|Read by Suzie when the project starts so native PAYDAY 3 runtime classes can be generated and registered in the editor.

|Wwise `ThirdParty` SDK files
|Required by the modkit's modified Wwise plugin and needed for support for PAYDAY 3 cooked audio assets.
|===

For the setup sequence, see xref:getting-started:wwise-setup.adoc[Set Up Wwise] and xref:getting-started:install-modkit.adoc[Install the Modkit].
