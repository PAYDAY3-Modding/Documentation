= SBZVariationEditActor
:description: Repairs missing links between variation preview components.

`SBZVariationEditActor` connects its mesh components to its assigned variation editor component. It fills missing links while preserving component references that are already assigned.

For the implementation API, see xref:suzie-native-bodies.adoc[Suzie Native Bodies API].

Blueprint subclasses inherit applicable callbacks. These are modkit Editor behaviours; Forge does not package the native bodies into the game.

== Implemented functions

This file supplies editor callbacks only. Internal C++ helpers are not additional Blueprint nodes.

== Editor callbacks

These run automatically and are not Blueprint-callable functions.

[cols="2,3",options="header"]
|===
|Callback |When it runs

|`SUZIE_POST_INITIALIZE`
|Runs after defaults and required loading are ready.

|`SUZIE_PROPERTY_CHANGED` for `VariationComponent`
|Responds automatically to a Details-panel property edit.

|`SUZIE_PROPERTY_CHANGED` for `SkeletalMeshComponent`
|Responds automatically to a Details-panel property edit.

|`SUZIE_PROPERTY_CHANGED` for `StaticMeshComponent`
|Responds automatically to a Details-panel property edit.

|`SUZIE_REFRESH`
|Runs when a watched dependency changes or becomes available.
|===

Initialisation, component-reference edits and watched component changes repair missing links. When a link is filled, the variation component is refreshed. Configure `Variation Set` and `Current Variation Idx` on that component as described on xref:sbz-variation-edit-component.adoc[SBZVariationEditComponent].

== Known limitations

* The actor does not create missing preview components or choose an appearance itself.
* No extra Blueprint-callable native functions are supplied by this file.

For asset creation and preview steps, see xref:custom-heists:variations.adoc[Variations].
