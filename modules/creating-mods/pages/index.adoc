= Creating Mods
:page-social-image: /payday3-modding/creating-mods/_images/heist-level-blueprint-example.png
:page-social-image-alt: A PAYDAY 3 Level Blueprint showing heist startup logic and bag-secured objective progression.

This section contains task-oriented guides for building PAYDAY 3 mods after you have completed the beginner setup.

Start with the mod type closest to what you want to change. For runtime-heavy mods, also read xref:pdml:index.adoc[PDML].

If your mod exposes player-configurable options, see xref:pdml:settings.adoc[Mod Settings] for toggles, floats, colors, keybinds, strings, and multiple choice settings.
