= Meshes

Meshes are 3D objects in the game. A `Static Mesh` has no skeleton; a `Skeletal Mesh` uses a skeleton for animation.
This guide covers replacing both types.

[NOTE]
====
This guide assumes you know the basics of Blender and FModel.
====

== Before you start

Read xref:getting-started:fmodel-setup.adoc[Fmodel setup] and xref:modkit:cooked-assets.adoc[Cooked Assets] before continuing. Even if you have made PAYDAY 3 mods before, check these pages for the current workflow.

== Find the model you want to replace

Locate the original cooked model in the Content Browser under `/Game/...`.

Open the model in read-only mode first and inspect any defaults, references, materials, parent classes, or other information that may be useful when recreating the modified version.

== Uncook the model

Theres no requirement to uncook the dependencies like the `skeleton` and the `physical asset` when it comes to Skeletal meshes.

[NOTE]
====
While Some skeletal meshes do have `Physical asset` some on the other hand dont have it, and when replacing the model you should use the new `Physical asset` that gets generated when importing the model if the original mesh had physical asset.  
====


== Import the model into Blender

After you get the model exported from Fmodel you will open it in blender, for you to be able to open it in blender you will need to install this extention https://github.com/DarklightGames/io_scene_psk_psa[psk/pskx importer]


== General Rules in Blender

For both mesh types, keep the model at the intended size to avoid unwanted clipping in the game.

== Importing the model into UE Editor

When importing your edited model into UE first drag and drop your `.fbx` into your mods folder (if you are importing a skeletal mesh make sure you also select the correct skeleton in the import settings)

[WARNING]
====
Some meshes can have `CPU access` checked, please make sure your mesh also has this setting enabled/disabled depending on the original mesh or your mod might cause the model to not show or in worst case crash your game. 
====

After that you will go back to where the original game asset is and delete it,
when deleting it there is a possibility that the project will ask you if you want to `force delete` or `replace reference`,
you will select the `replace reference` option and select your modded model, this will make sure the rest of your project doesnt possibly get messed up.
If the project wont give you this option you can simply delete the mesh.
From here you will take the mesh that is in your mods folder and move it to the folder where the original model was.


== Your mod/PAL Setup

For your PAL setup you will want to include only the Static or Skeletal mesh, and keep the rest of the assets like materials, physical asset and textures in your mod folder.

[WARNING]
====
Including the "Skeleton" in your PAL will most likely result in your mesh not loading or your game crashing when the game will try to render the mesh.
====

== General workflow

The general workflow for mesh replacement is:

. Find the asset that you are looking for.
. Uncook the model.
. Get the model from Fmodel and import it into Blender.
. Do your modifications to your model (adjust, edit, completely swap).
. Make sure you configured the structure in blender right.
. Export the model with proper settings depending on the mesh type.
. Import and replace the uncooked asset with your model under the same name, if importing skeletal mesh make it refer to the proper skeleton.
. Setup your PAL properly.
. Package and test out your mod.
