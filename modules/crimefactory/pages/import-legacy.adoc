= Import Legacy Mod

*Import Legacy Mod* is a migration workflow for older PAYDAY 3 UE4 logic mods created before the current CrimeFactory plugin structure.

image::importLegacy-navigation.png[Crime Factory toolbar with the Import Legacy Mod Button highlighted, width=1200]

It is intended to help move an existing mod project into the current modkit rather than recreating every asset by hand.

== Legacy UE4 layout

Older logic mods commonly stored their content under paths such as:

[source,text]
----
Content/Mods/
----

with mod metadata under:

[source,text]
----
Content/Mods/ModMeta/
----

The current CrimeFactory workflow instead creates each mod as its own Unreal plugin under the modkit's `Mods` directory.

== Importing

To import a legacy mod:

. Open CrimeFactory.
. Choose *Import Legacy Mod*.
. Select the folder containing the mod files from the previous UE4 project.
. Allow CrimeFactory to migrate the assets it finds into the current modkit project.
. CrimeFactory creates a new CrimeFactory mod plugin for the imported mod.
. The migrated assets are moved into that new plugin.

The result can then be managed like a normal CrimeFactory mod.

== After migration

After the import, review the new plugin before Forging it.

In particular:

* check the migrated assets and references,
* review the generated mod metadata,
* validate the PAL and Asset Manager setup,
* resolve any stale or project-specific references left from the UE4 version,
* and run CrimeFactory validation before Forge.

The legacy importer is a migration aid. It does not make every older project assumption automatically valid for the current UE5 modkit.
