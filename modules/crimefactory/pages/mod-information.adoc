= Mod Information & Configuration

CrimeFactory exposes information and configuration actions directly on each mod card.

== Information

Click *Information* to open the mod's properties.

== Configuration

Click *CONFIG* on a mod card to open that mod's CrimeFactory configuration.

image::config-button.png[CONFIG button on a CrimeFactory mod card, width=150]

The Config window exposes plugin/mod metadata such as:

* Icon
* Version
* Version Name
* Semantic Version
* Friendly Name
* Description
* Created By
* Links
* Dependency information

image::CrimeFactory-mod-properties.png[Mod Properties window showing the icon and version and descriptive metadata fields, width=820]

Use this window for metadata that describes the mod rather than gameplay content stored inside the plugin.



The configuration is where the PAYDAY-specific packaging setup for the mod can be reviewed and managed.

CrimeFactory uses this configuration together with the mod's PAL, Asset Manager registration, and replacement asset list when validating and Forging the mod.

See xref:pal.adoc[PAL & Explicit Assets] for the content-selection side of that configuration.

== PAL status and setup

CrimeFactory's information/validation tooling can inspect the mod's Primary Asset Label and related setup, including:

* the expected `PAL_<ModName>`,
* runtime label configuration,
* Chunk ID,
* explicit assets,
* Asset Manager registration,
* stale template placeholders,
* and external `/Game/...` replacement assets.

Issues detected here are also used by the Forge preflight.

See xref:validation.adoc[Validation].
