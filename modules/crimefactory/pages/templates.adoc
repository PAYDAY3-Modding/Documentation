= Templates

CrimeFactory templates create the initial plugin structure and PAYDAY-specific assets needed for common mod types.

image::CrimeFactory-new-mod-window.png[CrimeFactory template selection, width=1000]

== Blank

Use *Blank* for a general-purpose mod.

The template creates the new mod plugin and its standard CrimeFactory assets, including:

* `PAL_<ModName>`
* `DA_<ModName>`

image::blank-template.png[Assets generated by the Blank mod template, width=500]

This is the normal starting point when a more specialized template is not required.

== Logic Mod

Use *Logic Mod* when the mod's main purpose is Blueprint/runtime behavior through PDML.

In addition to the normal mod structure, CrimeFactory creates a Blueprint derived from PDML's `ModActorBase` and names it:

[source,text]
----
BP_<ModName>
----

image::logic-template.png[Assets generated by the Logic Mod template, width=500]

The mod data asset is populated with the discovered Mod Actor so PDML can use the generated logic mod structure.

== Custom Heist

Use *Custom Heist* when creating a new heist.

The template creates the normal mod structure plus the initial heist content, including:

* a `PD3HeistDataAsset`,
* a level named `LVL_<ModName>`,
* the generated heist added to the mod data asset's `Heist` array,
* and the heist data asset's `LevelPath` set to the generated level.

image::heist-template.png[Content generated by the Custom Heist template, width=500]

image::heistInner-template.png[Heist template folder containing manager data assets and the heist level, width=500]

This provides the basic CrimeFactory/PDML registration structure before the heist itself is authored.

== Future templates

Additional specialized templates are planned, including templates for areas such as HUD mods and audio mods.

They are not part of the current CrimeFactory release and should not be assumed to exist until they are added to the tool.
