This switch group is used to differentiate different audio reflections based on distance from the emitted sound source.

This can be used with Weapon SFX setups.

[cols="1,1"]
|===
|Switch Names | Info 

|close
|Reflection is emitted close to player.

|far
|Reflection is emitted far from player.

|mid
|Reflection is emitted partially far from player.

|===
