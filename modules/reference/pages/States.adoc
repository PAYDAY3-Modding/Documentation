= States

List of all the states that can be referenced for Wwise Audio Creation(s)

[NOTE]
====
This includes state groups and their states with info on each of them.
====


== acoustic_flag

Different audio handling depending on acoustic_flag state


[cols="1,1"]
|===
|State Name | Information 

|indoor_large
|Acoustic of large interior environments

|indoor_small
|Acoustic handling of small interior environments

|outdoor_hard_surface
|Acoustic of outdoor hard surface environments


|outdoor_small
|Acoustic of small outdoor environments (Alleys, patios,etc)

|outdoor_street
|Acoustic of outdoor street environments

|===

== Ai_state

Different voice audios/effects to be played depending on SINS state

[cols="1,1"]
|===
|State Name | Information 

|broken
|Condition of SINS is Broken

|glitchy
|Condition of SINS is Glitchy

|neutral
|Condition of SINS is Neutral (No Effects)

|===

== bag_foley

Different audio to be played depending on type of bag

[cols="1,1"]
|===
|State Name | Information 

|body
|Bag type is body bag

|money
|Bag type is money bag (loot)

|tool
|Bag type is tool (zipline, thermite, etc)
|===

== echo_flag 

Different echo(s) to be emitted based on environment type.

[cols="1,1"]
|===
|State Name | Information 

|alley
|Echos to be triggered in alley environments (small outdoor locations)

|generic
|Echos to be triggered based in general environments

|hard_surface
|Echos to be triggered in hard surface environments

|indoor
|Echos to be triggered in indoor environments

|===
