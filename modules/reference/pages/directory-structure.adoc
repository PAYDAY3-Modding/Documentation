= Directory Structure

The normal runtime layout for PDML mods keeps community mods outside PAYDAY 3's base cooked-content directory.

== PAYDAY 3 root

[source,text]
----
PAYDAY3/
|-- Content/
|   `-- Paks/
|       `-- ... base game cooked content ...
|
`-- Mods/
    |-- MyMod/
    |   |-- MyMod.uplugin
    |   `-- ... forged mod files ...
    |
    `-- AnotherMod/
        |-- AnotherMod.uplugin
        `-- ...
----

== Content/Paks

`PAYDAY3/Content/Paks/` is part of the game's own cooked content layout.

Normal CrimeFactory/PDML mods should not be installed here.

== Mods

`PAYDAY3/Mods/` is the dedicated PDML mod directory.

CrimeFactory creates mods as Unreal plugins and Forge produces the content intended for that mod. Install the complete forged mod folder here so PDML can discover and handle it.
