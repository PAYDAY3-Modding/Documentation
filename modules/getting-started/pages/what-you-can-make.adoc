= What You Can Make

The modkit is designed to cover more than traditional asset replacement.

== Common mod categories

=== Asset replacements

Replace compatible game assets with mod-owned content.
Examples include textures, materials, meshes, etc... 

=== Blueprint and logic mods

Use *Blueprint*, Unreal Engine's visual scripting system, to connect nodes that control game behaviour. The modkit exposes PAYDAY 3 classes and functions for these scripts, and PDML integrates the mod with the running game.

=== HUD and UI mods

Create or replace widgets, the building blocks of on-screen interfaces. HUD means the heads-up display shown during play; UI means user interface, including menus. Use PDML for runtime integration where required.

=== Custom heists

CrimeFactory includes a custom-heist template and the toolchain is being expanded with PAYDAY-specific authoring tools.
Custom heist development is more advanced than the first-mod tutorial. Finish Getting Started before moving to xref:custom-heists:index.adoc[Custom Heists].

=== Additive content

Support for adding new content such as gameplay items is an evolving part of the toolchain. Individual guides identify whether a workflow is supported, experimental, or still in progress.

== Current limitations matter

Not every system that exists in PAYDAY 3 can be authored completely in the editor yet.

For example, systems that depend on unavailable native generation steps may require additional runtime handling or further tooling.
The documentation treats these as explicit limitations rather than hiding them behind incomplete instructions.
