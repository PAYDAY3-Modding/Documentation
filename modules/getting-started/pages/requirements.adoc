= Requirements

Before installing the modkit, prepare the following.

The setup order is: custom editor, FModel, Wwise SDK, then the modkit project. The following pages walk through each one. Install the Wwise SDK even if your first mod only changes textures; the project depends on the bundled Wwise plugin.

== Required

* A legitimate installed copy of PAYDAY 3.
* The custom PAYDAY 3 Unreal Engine {pd3-engine-version} editor build used by the modkit.
* The PAYDAY 3 modkit project.
* https://fmodel.app/[FModel] for browsing the installed game archives and extracting setup data.
* An Audiokinetic account and the Audiokinetic Launcher so you can obtain the Wwise 2023.1.15 SDK files required by the modkit.

== Development tools

If you will compile the editor, project, plugins, or native modules, install a compatible Visual Studio C++ toolchain.

You do not need to write C++ for the first-mod tutorial. The toolchain may still be needed to build missing project or plugin modules. xref:install-modkit.adoc#_starting_the_project[Starting the Project] covers the Wwise module error and the build steps if you encounter it.


== Before continuing

Launch PAYDAY 3 normally at least once and make sure the base game installation works.

Next: xref:install-editor.adoc[Install the Custom Editor]. FModel is configured immediately afterwards in xref:fmodel-setup.adoc[Set Up FModel], followed by xref:wwise-setup.adoc[Set Up Wwise].
