= Set Up Wwise
:description: Install the matching Audiokinetic Wwise SDK and prepare the ThirdParty files required by the PAYDAY 3 modkit.

Wwise is the audio system used by PAYDAY 3. The modkit includes a modified Wwise plugin, but leaves out the Audiokinetic SDK libraries and other non-text `ThirdParty` files. The SDK is the set of development files the plugin needs.

You must obtain those files yourself from Audiokinetic and place them into the Wwise plugin included with the modkit.

Complete this setup even if you are making a texture mod. On this page, install the SDK and locate its folders. Copy them into `ThirdParty` after downloading the modkit on the next page.

[IMPORTANT]
====
The Wwise plugin included with the modkit is a modified integration based on *Wwise 2023.1.15.8789.3579*.

Use the matching Wwise 2023.1.15 SDK files. Do not install the latest Wwise SDK and assume it is compatible.
====

== What the modkit includes

The modkit already contains the modified Wwise plugin source and redistributable text files required by the project.

It does *not* include the Audiokinetic `ThirdParty` SDK payload, including the libraries and other non-text files that would normally be supplied with a complete Wwise Unreal integration.

This means you should not replace the Wwise plugin in the modkit with a stock plugin downloaded from Audiokinetic. You only need to obtain the matching Wwise SDK and restore the missing `ThirdParty` content into the plugin that is already present.

== Install the Audiokinetic Launcher

Download and install the https://www.audiokinetic.com/download/[Audiokinetic Launcher].

Sign in with an Audiokinetic account. If you do not already have one, create an account when prompted.

image::audiokinetic-download.png[Audiokinetic website with the Windows Launcher download highlighted, width=800]

Audiokinetic uses the Launcher to install specific Wwise versions, SDK packages, integrations, and platform files.


== Install Wwise 2023.1.15

In the Audiokinetic Launcher:

. Open the *Wwise* page.
. Choose *Install New Version*.
. Select the Wwise 2023.1.15 release that matches the modkit integration.
. Make sure the Wwise SDK and Windows x64 platform files are installed.
. Complete the installation.

The modkit integration is based on:

[source,text]
----
Wwise 2023.1.15.8789.3579
----
image::wwise-install.png[Audiokinetic Launcher Wwise page with the version selection controls highlighted, width=800]

[WARNING]
====
Do not use the Launcher's *Integrate Wwise into Project* action on the PAYDAY 3 modkit.

The modkit already contains a modified Wwise integration. Running the normal integration process can replace or modify the plugin files that the modkit depends on.
====

== Locate the Wwise SDK

After installing Wwise, locate its `SDK` directory.

Under your *Audiokinetic installation root*, locate the matching Wwise SDK at a path similar to:

[source,text]
----
<Audiokinetic installation root>\Wwise 2023.1.15.8789\SDK\
----
image::SDK-location.png[File Explorer showing the SDK directory for Wwise 2023.1.15.8789, width=800]

The exact path can differ depending on where Audiokinetic and Wwise were installed.

The SDK directory contains the headers and platform libraries that are omitted from the modkit.

== Copy the SDK folders into `ThirdParty`

This final copy step is performed after you have downloaded and extracted the modkit on the next page.

Locate the modified Wwise integration inside the modkit. For the Wwise 2023.1 integration, the SDK payload belongs in the `ThirdParty` directory under the bundled `Wwise` plugin:

[source,text]
----
<ModkitRoot>\Plugins\Wwise\ThirdParty\
----

image::thirdParty-location.png[File Explorer showing ThirdParty inside the bundled Wwise plugin, width=800]

[NOTE]
====
If the `ThirdParty` directory does not exist, create it.
====

From the installed Wwise `SDK` directory, copy the following into the modkit's `ThirdParty` directory:

* `include`
* `x64_vc160`
* `x64_vc170`

For example, the resulting layout should resemble:

image::payload-showcase.png[Wwise ThirdParty folder containing include and the x64_vc160 and x64_vc170 SDK folders, width=800]

Copy `x64_vc160` and `x64_vc170` from the matching Wwise 2023.1.15 SDK into this directory. Do not rename the SDK directories.

*Check after copying:* `ThirdParty` should contain `include`, `x64_vc160`, and `x64_vc170` directly, as shown above. If they are inside an extra `SDK` folder, move those three folders up into `ThirdParty` before opening the project.

[NOTE]
====
Audiokinetic's engine-plugin installation documentation also lists `Mac` and any additional platform SDK folders when those platforms are being targeted.

The PAYDAY 3 modkit workflow documented here is for Windows, so the matching Windows x64 SDK content is the important platform payload.
====

== Why this is required

The matching Wwise SDK is required to build or open the modkit and to work with PAYDAY 3 cooked audio assets.

Missing or incorrect `ThirdParty` files can cause missing library, missing DLL, unresolved module, or plugin load errors. Use the matching Wwise 2023.1.15 files described above.

.Why the plugin needs a matching SDK
[%collapsible]
====
The text/source portion of the Wwise integration can exist in the modkit without the complete Audiokinetic SDK payload, but Unreal still needs the matching Wwise headers and libraries when compiling or linking the plugin.

The modified integration also supports loading PAYDAY 3's cooked audio assets in the editor, so the SDK setup matters even if your mod does not change audio.

The Wwise version matters because the bundled plugin has been modified against the 2023.1.15.8789.3579 integration. Mixing SDK files from another Wwise release can introduce API, binary, or build-script mismatches.
====

== Before continuing

At this point, make sure:

* the Audiokinetic Launcher is installed;
* Wwise 2023.1.15 and its SDK are installed;
* you know where the Wwise `SDK` directory is located.

After downloading the modkit on the next page, copy the required SDK folders into its bundled modified Wwise plugin before attempting to build or open the project.
