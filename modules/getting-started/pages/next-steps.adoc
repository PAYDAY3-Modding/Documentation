= Next Steps

Once the first mod Forges and loads successfully, choose the area that matches what you want to build.

== Learn the environment

Read xref:modkit:index.adoc[The Modkit] if you want to understand the custom editor, reflected game types, cooked assets, and project structure.

== Build a normal mod

Go to xref:creating-mods:index.adoc[Creating Mods] for task-oriented guides covering replacements, Blueprint logic, UI, materials, meshes, and other mod types.

== Build a custom heist

Go to xref:custom-heists:index.adoc[Custom Heists].

Custom heists combine more systems than a basic mod, so they assume you already understand creating and packaging a normal mod.

== Learn PDML

Read xref:pdml:index.adoc[PDML] when your mod needs runtime initialization, mod settings, shared APIs, or other loader-integrated functionality.
