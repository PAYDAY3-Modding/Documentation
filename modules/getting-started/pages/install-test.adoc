= Install and Test

The final step is to install the forged mod and load it through PDML.

== Runtime prerequisite

PDML is the runtime mod loader used by CrimeFactory mods.

CrimeFactory creates mods as Unreal plugins, and PDML discovers and handles those plugin-based mods when PAYDAY 3 starts.

== Install the forged mod

Place the forged mod in:

[source,text]
----
PAYDAY3/Mods/
----

For example:

[source,text]
----
PAYDAY3/
`-- Mods/
    `-- MyFirstMod/
        |-- MyFirstMod.uplugin
        `-- ...
----

Use the folder produced by CrimeFactory rather than moving only an individual `.pak` file out of it.

[IMPORTANT]
====
PDML mods belong in `PAYDAY3/Mods/`.

Do not install normal CrimeFactory/PDML mods into `PAYDAY3/Content/Paks/`.

Keeping mods in the dedicated `Mods` directory separates community mods from the game's own cooked content and gives PDML a clean location to discover and manage them.
====

== Launch PAYDAY 3

Start the game with PDML installed.

Verify that PDML initializes successfully before diagnosing the individual mod.

Then verify that your newly forged mod is discovered and loaded.

== If the game does not load the mod

Check, in this order:

. The Forge completed without cook errors.
. The complete mod folder is under `PAYDAY3/Mods/`.
. PDML initialized successfully.
. The plugin and mount structure matches the selected mod type.
. Required dependencies are present.
. The game and modkit versions are compatible.

See xref:troubleshooting:index.adoc[Troubleshooting] for error-oriented guides.

== You now have the complete pipeline

You have gone through the fundamental workflow:

[source,text]
----
Create plugin mod
  -> Author
  -> Validate
  -> Forge
     -> Cook selected assets
     -> Package mod
  -> Install to PAYDAY3/Mods/
  -> PDML loads mod
  -> Test
----

That same pipeline is the foundation for more advanced PAYDAY 3 mods.
