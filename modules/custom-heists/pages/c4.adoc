= C4 - Explosive Charges

To setup C4 Charges for your custom heist you'll need 2 BPs:
- `BP_DAT_C4Explosive_01_Location_C` (for the location to plant the C4)
- `BP_DAT_C4Explosive_Pickup_C` (as the actual Item the player picks up)

Both of these BPs can be found under: `/All/Game/DLCs/00005-DLCHEIST0001/Environment/_Common/Interactable/DAT_C4Explosive_01`


== Map Setup
To use these 2 BPs you just place both of them wherever you like.
Afterwards navigate to the `Level Blueprint` while having the `BP_DAT_C4Explosive_01_Location_C` selected.


image::c4_SettingEnableState.png[How to enable the C4 Locations to be actually visible and interactable to the Player., width=800]

You'll have to use these blueprint nodes to activate the C4 Locations to be able to plant the C4. Whether you do this in the `Begin Play` Event or somewhere else doesnt matter.


image::c4_ServerEvent_HowToTriggerSomethingFromC4.png[How to enable the C4 to trigger something after blowing up., width=800]

In order to actually do something with the C4 you'll have to use the Server Event `Server On Exploded` and hook up anything you want to trigger afterwards.



== Customising the C4 Explosion Site

If you want to customise the C4 Site, such as having it that the player needs to plant more than one C4 or altering the damage it deals. Click on the `Details` when selecting the `BP_DAT_C4Explosive_01_Location_C` in your map.

Afterwards just change whatever settings you like and you're done.
