= Interactions

SBZ has a custom interaction class called `SBZInteraction`. You can add this component to any blueprint to make it interactable.

== Interaction location

By default, the interaction is bound locally to 0 0 0 in the blueprint's local location. To change this:

. Add a new component (typically a static mesh) and move it to the location you want the interaction to be.
. In `SBZBase Interactable Component`, open `Shapes`.
. Set the component type to the type of the component you just made, and the component name to that component's name.

The interaction is now located at that component's transform.

== Interaction settings

* Use `Completed Comment` to add a voiceline to whoever interacts with the component.
* Use the `Interaction query` and `shared key item query` to require an item for this interaction (e.g., a keycard is needed to use it).
* Use `gameplay effects on interact` to give players an item when they interact.
* Use `Normal distance` to change the interaction distance.
* `duration` to change how long it takes (0 = instant).
* `text` to change the interaction text that appears before interacting.
* Change `animated interaction data` to change the animation that gets played while a player interacts.
* Use the checkboxes in the `SBZInteractable` component to change key properties, such as whether the interaction is illegal, allowed in casing, or enabled on startup of the heist.
